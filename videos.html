Video and equivalent pathways

Every section works without a video. Where a public clip is verified, the equivalent path remains available for access, bandwidth and classroom choice.

Module 1

Ready to work safely

Section 1.1 · equivalent pathway

Personal hygiene and readiness

Person-to-place contamination audit

Purpose prompt: No video is required. Track one possible contaminant from a person or personal item to ready-to-eat food and identify the action that breaks the chain.

Accessible equivalent: Read ‘Why handwashing works’ and ‘Clothing, hair and personal items’. Use the handwashing image to identify the control being applied. Then compare the two written readiness scenes in Applied activity 1.1, build one contamination chain and justify where the strongest early control belongs.

Return to section

Section 1.2 · equivalent pathway

Contamination, temperature and food safety

Hazard-route investigation

Purpose prompt: No video is required. Which control stops each hazard earliest: separation, cleaning, time or temperature?

Accessible equivalent: Trace the raw-food, salad and probe-thermometer setup in the image. Identify the separation control and the temperature check, then use the section theory to add cleaning, time and recontamination controls that cannot be seen in one photograph.

Return to section

Section 1.3 · equivalent pathway

Safe decisions and incident response

Stop–isolate–tell scenario walkthrough

Purpose prompt: No video is required. What is the safest first action, and what should wait for an authorised person?

Accessible equivalent: Use the spill-response image as one worked example. Then use the four written incident cards in Applied activity 1.3 to record an observed fact, possible harm, immediate stop–isolate–tell action and one prevention change for each.

Return to section

Module 2

Food and the body

Section 2.1 · equivalent pathway

Six nutrients and their roles

Nutrient-team food map

Purpose prompt: No video is required. Which two foods contribute to the same body function through different nutrient combinations?

Accessible equivalent: Name the foods visible in the overhead spread. Link each chosen food to at least two possible nutrient contributions, group the links under energy, growth and repair or regulation, and explain why variety matters more than placing each food in only one box.

Return to section

Section 2.2 · equivalent pathway

Energy, growth and repair

Context changes the meal decision

Purpose prompt: No video is required. How do activity and timing change what counts as a suitable meal?

Accessible equivalent: Use the wrap-preparation image to identify possible carbohydrate, protein, plant-food and fluid contributions. Then compare the two written lunch options in Applied activity 2.2 for the supplied sport context, naming the portion or label evidence still needed.

Return to section

Section 2.3 · verified video

Digestion and nutrient absorption

How your digestive system works — Emma Bryce

Open video

Purpose prompt: Watch for the difference between moving food, breaking molecules down and absorbing nutrients.

Accessible equivalent: Use the classroom digestive-system model as an orientation image. Build a text flowchart from mouth to large intestine with three columns—organ, mechanical or chemical change, and what moves next—then mark only the absorption sites supported by the theory.

Return to section

Module 3

Reading food evidence

Section 3.1 · equivalent pathway

Ingredients, servings and nutrition panels

Label evidence-zone scan

Purpose prompt: No video is required. Which zone comes first for an allergen check, sodium comparison and portion estimate?

Accessible equivalent: Use the package photo only to locate likely evidence zones; do not invent values from blank generated panels. Apply the safety, comparison and portion passes to the complete fictional yoghurt labels supplied in Applied activity 3.1.

Return to section

Section 3.2 · equivalent pathway

Comparing foods fairly

Fair-comparison worked example

Purpose prompt: No video is required. Which apparent advantage disappears on the same-amount comparison?

Accessible equivalent: Use the equal bowls, scale and matching grids to explain what a fair comparison controls. Then use the paired fictional yoghurt data in Applied activity 3.2 to compare per 100 g first, calculate each whole tub and write a conditional recommendation.

Return to section

Section 3.3 · equivalent pathway

Marketing claims, ethics and health

Claim–evidence–omission audit

Purpose prompt: No video is required. Which element is evidence, which is persuasion and what remains unanswered?

Accessible equivalent: Use the front-versus-back package photo to notice how first impressions differ from evidence checking. Test the complete written Berry Crunch claims and ingredient list in Applied activity 3.3, then rewrite one claim more fairly.

Return to section

Module 4

Needs, habits and influences

Section 4.1 · equivalent pathway

Active non-nutrients and food variety

Equivalent pathway: trace what variety contributes

Purpose prompt: Look for two different ways a varied selection can support digestion or hydration without relying on a superfood claim.

Accessible equivalent: Name only the foods visible in the overhead spread. Trace one fibre-rich food, one water-containing food and two differently coloured plant foods to the section explanations, remembering that water is a nutrient and variety does not prove a superfood claim.

Return to section

Section 4.2 · equivalent pathway

Nutrition across the lifecycle

Equivalent pathway: lifecycle design case comparison

Purpose prompt: Look for the stated need in each case and the evidence that would justify adapting the food.

Accessible equivalent: Use the multigenerational meal image to separate observation from assumption. Then apply the written lifecycle case cards in Applied activity 4.2, adapting the base meal only from stated needs and circling information that would require confirmation.

Return to section

Section 4.3 · equivalent pathway

Personal, social, cultural and digital influences

Equivalent pathway: influence detective photo study

Purpose prompt: Identify at least four influences in the scene and decide which two are interacting most strongly.

Accessible equivalent: Observe the family, friend, food objects, reusable container and blank phone without inventing motives. Then use the written fictional sponsored post in Applied activity 4.3 to map personal, social, cultural, environmental and digital influences around one decision.

Return to section

Module 5

Patterns, technology and choice

Section 5.1 · equivalent pathway

Australian food-consumption patterns

Equivalent pathway: read a dietary-pattern claim

Purpose prompt: Identify the population, measure, time period and one limit before deciding what the pattern suggests.

Accessible equivalent: Treat the reusable lunches as examples of individual meals, not population data. Use the current ABS data card in Applied activity 5.1 to identify population, measure, date and limits before writing one supported pattern statement and one claim the data cannot support.

Return to section

Section 5.2 · equivalent pathway

Convenience, delivery and food technology

Equivalent pathway: follow a delivered meal

Purpose prompt: At which stage could time, temperature, contamination, cost or packaging change the quality of the final choice?

Accessible equivalent: Use the insulated meal-kit image to identify one convenience stage, one benefit, one control and one trade-off. Then order the written source-to-eating stages in Applied activity 5.2 and identify where safety, cost, access or packaging could change the outcome.

Return to section

Section 5.3 · equivalent pathway

Designing responsible food solutions

Equivalent pathway: walk through a design evidence cycle

Purpose prompt: At each stage, identify what new evidence helps the designer decide what to keep, change or confirm.

Accessible equivalent: Use the prototype image to identify measurable criteria such as portion, packaging and waste. Arrange the written need–criteria–alternatives–prototype–test–improve cycle in Applied activity 5.3, attach evidence to each stage and justify one testable improvement.

Return to section

Module 6

Health, guidance and HelloEats

Section 6.1 · equivalent pathway

Under- and overnutrition

Equivalent pathway: pattern, mechanism and context

Purpose prompt: For each case, distinguish what is observed, what mechanism is possible and what information would still be needed before drawing a conclusion.

Accessible equivalent: Use the anonymous meal-card image to distinguish a repeated pattern from a judgement about one meal or a body. Apply the three fictional cases in Applied activity 6.1 using evidence → possible mechanism → context → respectful support, without diagnosing.

Return to section

Section 6.2 · equivalent pathway

Nutrition-related conditions and prevention

Equivalent pathway: mechanism and risk-factor stations

Purpose prompt: For each condition, identify one mechanism, one modifiable factor, one non-modifiable factor and one claim that would overstate prevention.

Accessible equivalent: Choose one body-system model visible in the image and state its normal role. Use the matching theory heading to build a mechanism–risk–protective-factor chain, then rewrite any absolute prevention claim using accurate reduce-risk language and a professional-help boundary.

Return to section

Section 6.3 · equivalent pathway

Australian guidance and the HelloEats challenge

Equivalent pathway: guidance-to-design evidence walk

Purpose prompt: Identify which tool answers each design question and where a product score or label cannot decide for the designer.

Accessible equivalent: Use the meal-prototype image to identify what can be measured or tested. Apply the evidence-role card and paired fictional label data in Applied activity 6.3, then state plainly that any dates, marks, submission method or practical conditions come only from the current teacher-issued notification.
